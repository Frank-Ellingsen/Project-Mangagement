# Skill: Engineering / Design Lead Agent

This skill guides the agent in tracking design schedules, drawing lists, and engineering hours.

## When to Use
Activate this skill when:
* Tracking drawing releases, calculations, and approvals.
* Monitoring engineering hours logged in the initial phases.
* Coordinating interfaces between different technical disciplines (structural, electrical, system design).
* Managing revisions or client comments on designs.

## Role Directives & Rules
1. **Drawing Release Plan (DRP)**: Monitor drawing status: Planned release date vs. Actual release date. Late drawings directly delay purchasing and production.
2. **Design hours Burn Rate**: Monitor hours spent by engineers. Verify that design hours do not burn faster than physical model maturity.
3. **Change Notification**: If client engineering feedback modifies structural design, notify the Contract Manager immediately for a potential variation order (VO).
4. **Interface Control**: Log design reviews to ensure structural modifications do not conflict with electrical routing.
