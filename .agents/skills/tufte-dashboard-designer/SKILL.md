# Skill: Tufte Dashboard Designer

This skill instructs the agent on how to apply Edward Tufte's Data-Ink Ratio principles when formatting reports, designing BI schema visuals, or drafting report layout guides.

## When to Use
Activate this skill when:
* Asked to write styling guides, mockups, or design charts for Power BI, Excel, or Streamlit.
* Formatting tables, charts, S-curves, or resource histograms.
* Writing layouts for stakeholder reporting.

## Core Directives

### 1. Data-Ink Maximization
* **Eliminate Gridlines**: Never add background grids, frames, or borders to charts. Whitespace serves as the boundary.
* **Direct Labeling**: Place label names directly next to data curves, bars, or segments. Avoid separate legends/color keys that force eye-movement.
* **No Chart Junk**: Remove decorative icons, 3D shapes, shadow effects, and background card-fills.

### 2. Table Layout Standards
* **No Vertical Lines**: Never use vertical separators between columns.
* **Subtle Horizontals**: Only use thin horizontal borders under the headers and at the bottom of the table.
* **Alignment Rules**:
  * Left-align text columns.
  * Right-align numerical and currency columns.
  * Align decimal points vertically.
* **Common Units**: Place units (e.g. `NOK`, `hours`) in the column header only. Do not duplicate them in individual rows.

### 3. Chart Color Rules
* Keep colors muted and functional. 
* Use light grey for baselines/plans, dark grey/black for actuals, and blue/grey for earned progress.
* Reserve accent colors (like muted red or amber) exclusively to call out active risks or negative variances.
