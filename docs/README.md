# Documentation Folder Guide

This `docs/` folder groups non-runtime documentation to keep the project root focused on executable assets.

## Structure

- `concepts/` — AI, engineering, and project management concept writeups.
- `methodology/` — PM glossaries, frameworks, and theory references.
- `personal/` — Career/CV-related notes (ignored by Git via `.gitignore`).
- `release/` — Release notes and GitHub publication metadata.
- `templates/` — PDF templates and planning forms.
- `visuals/` — Mockups and image assets.
- `scratch/` — Temporary planning notes.

## Runtime impact

No runtime Python/PowerShell data paths were changed (`AI_Controller/`, `Data/`, `Reports/` remain unchanged).
