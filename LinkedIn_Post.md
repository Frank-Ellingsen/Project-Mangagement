🚀 **Introducing the Project Controlling & EVM Control Tower for Maritime & Engineering Projects**

Managing complex engineering and shipbuilding projects requires absolute visibility, precise forecasting, and real-time risk tracking. That’s why I built the **Project Controlling Control Tower**—a multi-layered, automated analytical system tailored for the maritime, defense, and composite manufacturing sectors.

This project goes far beyond a simple dashboard; it integrates a full analytical stack with agentic capabilities to audit portfolio performance and enforce data-driven controls:

📊 **Key Architectural Layers:**
1. 🦆 **Analytical Data Layer (DuckDB):** High-speed SQL engine compiling real-time views for WBS elements, cost/schedule variances (CV/SV), and Estimate at Completion (EAC/ETC) forecasting.
2. 🗄️ **Transactional Layer (SQLite):** Handles RAID logs and live audit logs for data integrity.
3. 💻 **Streamlit & Plotly Web App:** Interactive S-Curves and Gantt charts designed with strict adherence to **Edward Tufte’s Data-Ink Ratio** principles (no heavy borders, zero vertical gridlines, direct labeling).
4. 🌐 **Static HTML Dashboard:** Standalone, browser-ready Control Tower featuring a built-in *What-If Corrective Simulator* to model recovery actions for labor/material deviations.
5. 📊 **Power BI & Excel Integration:** Compiles complete `.pbip` projects (star schema, DAX measures) and generates formula-driven, live-calculated Excel reports using `openpyxl`.
6. 🤖 **13-Agent Skill Framework:** Specialized AI agents auditing the project portfolio from different perspectives: Financial Controller, Contract Manager, Procurement, Production, Quality, and Engineering.

💡 **Results Focused:**
By automating data verification, audit trails, and reporting, this tool empowers project managers and controllers to move from reactive tracking to proactive risk mitigation.
